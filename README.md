# 口述历史转写与标注编辑器

面向口述史项目的本地优先校对工作台。应用预置普通话校订轨、方言原音轨和英文字幕轨示例，可不依赖后端完成完整编辑闭环。

## 功能

- 导入 SRT、VTT 或每行 `[00:12] 文本` 格式的带时间码文本。
- 在多个转写轨之间切换，校正发言人、开始/结束时间、正文和 1—5 级置信度。
- 标记低置信词句、方言表达和专有名词；按文本光标比例拆分片段，或与下一片段合并。
- 把片段挂载到主题、事件和人物词条；重复关联自动去重。
- 词条库由编目组单独维护，校对员本机只读：导入编目组导出的 JSON 清单，按词条编号对账。
  - 两边各自持有版本；被合并的关联顺着合并目标（支持多级合并链）自动改挂。
  - 被停用且没有接续目标的片段断开挂载、标记“待重新归类”，由校对员改挂在用词条。
  - 清单只改词条与挂载，批注、回复、置信度、校对标记一律保留，清单缺省字段与本机旧值合并，空值不会冲掉本机数据；版本号倒退的清单行自动拒绝。
  - 一批导入只回滚失败行，已对上的行保留；失败行进入独立重试队列，下次打开编辑器只重试这些条目，也可在“导入词条清单 → 失败重试”里手动重试。
- 旧草稿（内嵌标注实体）首次打开时自动迁移：内嵌词条抽出建库，按名称回填编目编号，回填不上的保留并标“待回填”，批注与校对标记不动。
- 添加审校批注、逐条回复并标记解决状态。
- 支持 50 步撤销/重做，`Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 快捷键。
- 自动保存到 `localStorage`，刷新、关闭页面或断网后可继续编辑；`Ctrl/Cmd+S` 可立即保存。
- 使用 `BroadcastChannel` 与 `storage` 事件检测多标签页并发修改，不静默覆盖，由用户选择保留本页或载入另一标签页版本。
- 键盘校对：`J`/`↓` 下一片段，`K`/`↑` 上一片段，`R` 标记已校对，`M` 合并下一片段，`?` 打开快捷键帮助。
- 按当前轨道导出 SRT 字幕。

## 技术栈

- SolidStart 2 + SolidJS + TypeScript
- Kobalte（对话框、Tabs、Checkbox 等无障碍基础组件）
- Vite 8
- 浏览器 `localStorage`、`BroadcastChannel`
- nginx 静态部署

## 开发

需要 Node.js 24 或更高版本。

```bash
npm install
npm run dev
```

开发服务器地址以 Vite 输出为准。

## 构建与预览

```bash
npm run build
npm run preview
```

生产构建输出到 `dist/client`，其中包含可直接部署的 `index.html` 和静态资源。

## Docker

容器内由 nginx 监听 `80`，宿主端口按根端口表映射为 `10007`。

```bash
docker build -t sologsb-1007 .
docker run --rm -p 10007:80 sologsb-1007
```

访问 `http://localhost:10007`。

## 数据说明

项目、轨道、片段和批注保存在当前浏览器的 `localStorage`（schema 2）。词条库来自编目组导出的清单，本机只读，不新建、不改写词条本身。只读预览或本地数据不会上传到服务器；清理浏览器站点数据会清除草稿。多标签冲突不会自动合并，以避免覆盖人工校对结果。

导入失败的清单行单独存于 `sologsb-1007-pending-terms-v1`，与草稿解耦：草稿回滚或载入其他标签页版本都不影响失败重试队列。

旧版草稿（schema 1，标注实体内嵌在项目里）会在首次打开时自动迁移到词条库，迁移结果以顶部横幅提示。

## 词条清单格式

编目组导出 JSON，裸数组或带清单头均可：

```json
{
  "catalogVersion": "2026-10-03-r4",
  "exportedAt": "2026-10-03T09:00:00+08:00",
  "rows": [
    { "code": "T-001", "name": "码头生活", "type": "topic", "color": "#2563eb", "status": "active", "version": 4 },
    { "code": "T-003", "status": "merged", "mergeTargetCode": "T-001", "version": 4 },
    { "code": "P-002", "status": "retired", "version": 4 }
  ]
}
```

字段缺省时与本机已有词条合并（不清空名称/颜色/类型）；`merged` 必须带 `mergeTargetCode`，目标缺失、停用或合并成环的行进失败队列。对话框中可“下载清单模板 / 填入示例”试用。
